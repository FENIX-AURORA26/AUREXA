# Android roadmap (KVP_STUDIO)

Como este projeto usa PyQt5, o caminho mais estável para Android é:

1. Manter backend/API atual (`server.py` + `https://aurexa-api.onrender.com`).
2. Criar app mobile dedicado (Kivy, Flutter ou React Native).
3. Reusar autenticação/licença/plano da API.

Scripts de apoio:
- `build_android.sh` (gera guia e checklist de build)

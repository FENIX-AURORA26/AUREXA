# Dev Area Completa (KVP_STUDIO)

Esta area foi criada para voce desenvolver apps/programas como um mini "modo desenvolvedor".

## Ferramentas

- `studio/tools/create_project.py`: cria projeto base rapidamente.
- `build_release.ps1`: empacota para Windows.
- `build_release_linux.sh`: pacote Linux.
- `build_macos.sh`: build macOS (em Mac).
- `build_android.sh`: guia Android.

## Fluxo sugerido

1. Criar projeto com `python studio/tools/create_project.py`
2. Implementar features
3. Rodar testes
4. Gerar build por plataforma
5. Publicar

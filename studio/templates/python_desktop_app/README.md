# Python Desktop App Template

Template simples para novos apps desktop da Fenix Boreal.

## Estrutura sugerida

- `app_main.py`
- `ui/`
- `services/`
- `core/`
- `tests/`
- `.env.example`
- `requirements.txt`

## Checklist inicial

- definir nome do app
- criar logo em `branding/`
- configurar `.venv`
- criar `README.md`
- separar config, UI e servicos
